# Pallavi Patel | B.Tech AIML Student Portfolio

A modern, responsive, and student-focused personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**.

---

## 👤 Profile

- **Name**: Pallavi Patel
- **Role**: B.Tech Computer Science Student specializing in Artificial Intelligence and Machine Learning (AIML)
- **College**: Gyan Ganga Institute of Technology and Sciences (GGITS), Jabalpur
- **Duration**: 2024 – 2028 (Expected Graduation: 2028)

---

## 🚀 Sections Included

1. **Home**: Hero introduction, B.Tech AIML student subtitle, student configuration snapshot card, academic metrics, and quick action buttons (*View Projects* and *Contact Me*).
2. **About Me**: Student journey, interest in AI, ML, programming, and web development, along with teamwork and continuous learning values.
3. **Skills**: Attractive technical cards for Python, C++, HTML, JavaScript, Artificial Intelligence, Machine Learning, and Git & GitHub.
4. **Projects**:
   - **NetraAI**: AI-based document verification project.
   - **Crypto Fraud Detection**: Blockchain analytics and suspicious wallet identification.
   - **One Stop Personalized Career & Education Advisor**: Multilingual career guidance project.
5. **Education**: Detailed academic card for B.Tech in CSE (AIML) at Gyan Ganga Institute of Technology and Sciences, Jabalpur (2024–2028).
6. **Experience & Activities**: College volunteering, technical club participation, hackathons, and self-driven coding practice.
7. **Contact**: Editable email placeholder, college location, interactive contact form with instant validation, and direct GitHub/LinkedIn buttons.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Bundler & Dev Server**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Plus Jakarta Sans & JetBrains Mono

---

## 💻 How to Run the Project

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open your browser and navigate to:
```
http://localhost:3000
```

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in `/dist`.

### 4. Preview Production Build
```bash
npm run preview
```
